What does “burned” mean here?+

This tracker measures BOBO held by the project-designated BoboBurn address. Sending tokens to an address is different from a Solana token-burn instruction, which reduces the mint’s supply. Address balances alone do not prove that tokens are permanently unspendable.

Daily arrivals sum positive net changes to the tracked token account in finalized transactions. Outgoing changes are recorded separately; none appear in the verified history. Transactions can include transfers from sources other than GRR. The tracker does not attribute all arrivals to rewards.

Days run from 00:00 to 23:59:59 UTC. The current day is partial. Figures refresh every minute while this page is visible. When the page is reopened, history is reconstructed from on-chain records. A saved snapshot remains clearly dated if verification is unavailable.

All arithmetic uses the token’s six-decimal base units. The current balance is reconciled against the full retrieved history before the snapshot is marked verified. Verification slot: 460,296,442.
